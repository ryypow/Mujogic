STATE SPACE (72 states)
-----------------------
State ID = direction_bin * 36 + grasp_bin * 12 + speed_bin * 4 + progress_bin

Components:
1. DIRECTION_BIN (2 bins):
   - 0 = need positive rotation (goal_progress >= 0)
   - 1 = need negative rotation (goal_progress < 0)

2. GRASP_BIN (3 bins):
   - 0 = weak grasp (0-1 fingers in contact)
   - 1 = stable grasp (2 fingers in contact)
   - 2 = strong grasp (3+ fingers in contact)

3. SPEED_BIN (3 bins):
   - 0 = not spinning (angular_velocity_z < 0.02)
   - 1 = rotating (0.02 <= angular_velocity_z < 0.1)
   - 2 = fast rotation (angular_velocity_z >= 0.1)

4. PROGRESS_BIN (4 bins):
   - 0 = far from goal (remaining > 30 degrees)
   - 1 = getting there (15-30 degrees remaining)
   - 2 = acceptable (5-15 degrees remaining)
   - 3 = at goal (< 5 degrees remaining)

Total: 2 x 3 x 3 x 4 = 72 states

ACTION SPACE (5 actions)
------------------------
0 = GRASP    - Close all fingers
1 = RELEASE  - Open all fingers
2 = ROT_POS  - Rotate positive (+Z direction)
3 = HOLD     - Keep position
4 = ROT_NEG  - Rotate negative (-Z direction)
